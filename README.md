# Order-Fulfilment-Analysis-Project
# 📊 Order Fulfillment Dashboard

An interactive Excel dashboard created to analyze sales and order performance using transactional sales data.

## 🎯 Objective

To analyze order volume, revenue, product performance, and daily sales trends through an interactive dashboard.

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables & PivotCharts
- KPI Cards
- Slicers
- Data Formatting

## 📊 Dashboard Features

- Total Orders
- Total Revenue
- Average Revenue
- Average Discount
- Most Ordered Products
- Revenue by Product
- Daily Sales Trend
- Daily Revenue Trend
- Online vs Physical Visit analysis using a slicer

## 💡 Key Insights

- **794 orders** were analyzed.
- Total revenue was approximately **₹2.38 lakh**.
- **Crispy Chole Pizzabun** had the highest quantity ordered.
- **Paneer Tikka Pizzabun** generated the highest product-wise revenue.
- Daily sales and revenue showed fluctuations throughout the analyzed period.

## 📚 What I Learned

This project helped me improve my skills in Excel data analysis, PivotTables, PivotCharts, dashboard design, KPI creation, and interactive filtering using slicers.
